No card artworks linked in this file yet. Setup, step 3 links them.
1Connect to the AF1 Tool

In the AF1 Tool open Team Cards, Figma Sync, Setup and click Create plugin token. Paste it here. You do this once.

2Which campaign is this board?

The plugin builds and syncs the landing pages of one campaign per Figma board. On a board without landing pages, like the Team Cards board, skip this step.

3Link the card artworks

Open the page with the card designs. The plugin finds the artworks and guesses which card each one is. Check the guesses and link them. From then on a design change becomes the card image by itself.
